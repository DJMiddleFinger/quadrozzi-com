### 👉 [Visit the live site: djmiddlefinger.github.io/quadrozzi-com](https://djmiddlefinger.github.io/quadrozzi-com/)

| Site | Link |
|---|---|

| GBX Gowanus Bay Terminal | https://djmiddlefinger.github.io/quadrozzi-com/gbx/ |
| Be™ Brooklyn Equine | https://DJMiddleFinger.github.io/be-brooklyn-equine/ |
| Helping Hoof Initiative | https://djmiddlefinger.github.io/quadrozzi-com/helping-hooves/ |

The home page is a single no-scroll face page. The Q is really a mudflap: once per browser session a wireframe
mixer truck backs up until its flap fills the screen (`site/assets/js/truck-intro.js`, WebGL; open a new tab to replay,
and check its math with `node tools/test_truck.js`). Its model, `site/assets/truck.bin`, is built from an FBX by
`python tools/build_truck.py path/to/truck.fbx`. A four-bar button in the top left opens a side panel. The panel is an accordion of the
company's 8 divisions (Real Estate, Operations, Design, Recreational, Not-for-profit, Sponsorships, In the News,
Special), from the "Q website v.03.2 categories" brief. Companies with no site yet are plain text; edit them in
`site/index.html`.

GBX and Helping Hoof Initiative are multi-page sites that share `site/assets/` (styles, script, photos).
Each page has a sidebar for the top-level pages, a breadcrumb bar showing where you are, and buttons to the
pages one level down. GBX breadcrumbs start at Quadrozzi; Helping Hoof Initiative's start at its own home
and carry no Quadrozzi branding. Email addresses appear only on contact pages (`contact/` on each site), reached from every "Contact us" button; the inquiry forms send to info@Quadrozzi.com.

## Editing GBX or Helping Hoof Initiative
All copy, the page tree and the contact emails live in `tools/build_site.py`. Edit it, then run:
```bash
python3 tools/build_site.py
```
and commit the regenerated `site/gbx/` and `site/helping-hooves/` folders.

## Run locally
```bash
npm start
```
Then open http://localhost:8080.

## Sponsorships, In the News, Special
Each page searches a list in `site/assets/data/` (`sponsorships.json`, `news.json`, `special.json`), all empty for now.
Add entries as objects, then push:
```json
{ "date": "2026-10-16", "name": "Brooklyn Eagle", "title": "Optional headline", "category": "Equine", "company": "GBX™", "link": "https://..." }
```
`name` is the organization (or media outlet on In the News). `category` and `company` must match the dropdown
values in `tools/build_site.py` (`CATEGORIES`, `COMPANIES`, `LISTS`) to be filterable. Links like
`news/?category=Equine` open a page filtered.

## Forms (GBX booking, Helping Hoof Initiative get-involved)
The site has no server, so by default pressing **Send** opens the visitor's email app with every answer
filled in. Where messages go is set by `inquiry_config(...)` in `tools/build_site.py`:

| Page | Inbox |
|---|---|
| GBX › Book | info@Quadrozzi.com |
| Helping Hoof Initiative › Get involved | info@Quadrozzi.com |

Each config also takes an `endpoint`: a form service URL (e.g. Formspree) that receives submissions directly,
with no email app involved. You'll need to create the service account yourself. Links such as
`book/?type=Event&areas=Waterfront%20%26%20piers` preselect form options; the shared form code lives in
`site/assets/js/site.js`.

**Donations:** the Get involved page has a `HOOVES.donate` setting (in `DONATE` in `build_site.py`). Put an
online donation page there (PayPal, Givebutter, Stripe and so on) and the "Donate" button goes to it. While
it's empty, "Donate" opens the form with Donate selected.

## Photo credits
Most photos come from Wikimedia Commons (CC0, public domain or CC BY-SA). Each one is listed with its author
and license in `tools/credits.json`; photos with "hooves" in their path go on Helping Hoof Initiative's
credits page, the rest on GBX's. After adding or replacing a photo, update that file and rebuild. The credits
pages are linked from every page footer and meet the attribution requirement of the CC BY-SA photos.

## Deploy
Every push to `main` republishes the site through GitHub Pages (Actions).

Quadrozzi.com is hosted at Network Solutions, which needs a manual upload. Build the packages with:
```bash
python3 tools/package_zips.py
```
It writes `Quadrozzi-site-upload.zip` (the whole site) and `Quadrozzi-under-construction.zip` (home page only,
every menu item opens an "Under construction" page), then deletes any older zips so only the latest 2 remain.
Extract one into the hosting's `htdocs` folder.
